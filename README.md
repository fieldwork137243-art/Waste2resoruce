# Waste2Resource Atlas

Static public website for the Waste2Resource mine-waste reuse atlas.

## Airtable inventory

Import `case-studies-import.csv` into a new Airtable base named **Waste2Resource Atlas Inventory**. The base fields are:

- title
- location
- country
- region
- waste_stream
- reuse_pathway
- status
- evidence_level
- description
- source_url

Keep submissions in a separate **Submissions** table until a reviewer verifies the source and approves a case for the public inventory.
